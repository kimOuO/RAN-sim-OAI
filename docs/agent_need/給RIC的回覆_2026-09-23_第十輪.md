## 三、實際形狀(pci 模式,今日獨立程序渲染)

```json
"neighbors": [
  {"pci": 0, "arfcn": 633333, "rsrp": -58.7, "rsrq": -22.0, "ncgi": "208095-56bce6561"},
  {"pci": 2, "arfcn": 633333, "rsrp": -84.1, "rsrq": -43.0, "ncgi": "208095-db8cf0c57"}
]
"all_rsrp": [
  {"pci": 1, "arfcn": 633333, "rsrp": -47.4, "serving": true},
  {"pci": 0, "arfcn": 633333, "rsrp": -58.7},
  {"pci": 2, "arfcn": 633333, "rsrp": -84.1}
]
```

- `ncgi` 格式與 Agent 介面 I-2 相同:`<mcc><mnc 3 位>-<36-bit NCI 9 hex>`;NCI 與 E2 Setup `nodeConfigs` / KPM 同一套推導,貴方已解出的 `0x56bce6561` 等值直接對得上。
- `ncgi` 只在 CU 的 NRT 對該 serving cell 有**恰好一筆**該 (pci, arfcn) 的關係時附帶。缺漏鄰區(零筆)與混淆(多筆)都不附。上面的例子因走廊場景 NRT 已由 ANR 建齊,所以都有;要驗「不附」的情況,用 I-3 注入 `relation_change: remove` 後該 PCI 的 `ncgi` 會消失。
