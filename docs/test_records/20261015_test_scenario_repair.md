## 追加：控制事件來源分類

修正儀表板、RIC 頁與事件流將 RAN 自主事件混稱為 RIC/xApp 指令的呈現。三頁共用來源分類與計數：

| 歸檔來源 | 顯示分類 | 是否計入 RIC/xApp 指令數 |
|---|---|---|
| `ric/*` | RIC / xApp 指令 | 是 |
| `son/anr_auto` 等本地 SON 紀錄 | RAN 自主 SON | 否 |
| `son/ric_apply` | RIC 指令落地 | 否，與下發指令分開計數 |
| 其他來源 | 其他 | 否 |

RIC 頁增加來源類別篩選，來源統計與明細均顯示分類；事件流可分別開關各類事件。`applied` 的自主事件在儀表板也顯示成功狀態。

驗證：只有 SON、混合來源、空紀錄三組情境，在儀表板、RIC 頁、事件流的計數與篩選皆通過，未捕獲 JavaScript 頁面例外；TypeScript 與 ESLint 檢查通過。實際 test 歸檔當時為 6 筆 `son/anr_auto`、0 筆 `ric/*`，瀏覽器已確認顯示「RAN 自主 SON 6」與「RIC / xApp 指令 0」。本次修改為前端呈現與分類，沒有重新起場。
